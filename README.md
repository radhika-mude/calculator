# calculators

Two Python calculator programs.

## Programs Written

### simple_calculator.py
Takes two numbers and an operator (+, -, *, /) and prints 
the result. Handles division by zero.
- **Concepts used:** float(), input(), if/elif/else, division by zero check
- **Written:** April 2026

### grade_calculator.py
Takes a student's name and marks for multiple subjects, 
calculates the average, and assigns a letter grade (A–F).
- **Concepts used:** for loop, range(), f-strings, input(), average, if/elif/else
- **Written:** April 2026
